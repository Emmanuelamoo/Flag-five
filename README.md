# Flag Five by GoodPlay Sports Group (self-hosted)

1. Supabase (free): new project. SQL Editor: run supabase-setup.sql. Authentication > Sign In / Providers: turn on Anonymous sign-ins. Project Settings > API: copy Project URL and anon public key into config.js.
2. GitHub: upload every file, keeping the api folder.
3. Vercel: Add New > Project > import the repo > Framework Preset: Other > Deploy.
4. AI teams (optional): Vercel > Settings > Environment Variables: ANTHROPIC_API_KEY from console.anthropic.com, then Redeploy.
